# Sorting Algorithms

## Why Sorting Matters
Most array/string problems become easier once data is sorted.
Sorting is a prerequisite for Binary Search, Two Pointer, and many Greedy problems.

## Algorithms Implemented

| # | Algorithm | File | TC (Best) | TC (Worst) | SC | Stable? |
|---|-----------|------|-----------|------------|----|---------|
| 1 | Bubble Sort | Bubble_Sort.cpp | O(n) | O(n²) | O(1) | Yes |
| 2 | Selection Sort | Selection_Sort.cpp | O(n²) | O(1) | No |
| 3 | Insertion Sort | insertion_sort.cpp | O(n²) | O(1)  | Yes |
| 4 | Counting Sort |  Count_Sort.cpp | O(n + range) | O(range) | No |
